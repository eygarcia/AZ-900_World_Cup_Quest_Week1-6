# AZ-900_World_Cup_Quest_Week1-6
Ed Garcia used ChatGPT and provided the syllabus using content for Weeks 1-6 of the course and pointing to MSLearn content, Skillable Lab content, and the AZ-900 Ebook chapters students have been reading.  Goal:  Certification Prep:  Students can re-take simulation as needed, posting highest score (Hopefully 60 pts).   Used "IFrame to embed Github Code". 

For more details on how to build this type of interactive, fun and engaging content, contact Ed Garcia.  Have fun learning/practicing.

ChatGPT Prompt:
You are a senior instructional designer, front-end developer, accessibility specialist, and visual communicator specializing in Microsoft Azure and cybersecurity education for community college and undergraduate students.

Create an engaging, classroom-ready HTML5 learning game named:

“AZ-900 World Cup — Certification Quest from Weeks 1 through 6”

SOURCE MATERIALS

Use the attached course syllabus to determine exactly what was taught during Weeks 1–6. Build the questions and explanations from:

1. The topics, textbook chapters, assignments, and learning objectives identified for Weeks 1–6 in the attached syllabus.
2. The assigned Microsoft Learn modules and learning paths for Weeks 1–6.
3. The assigned e-book chapters for Weeks 1–6.
4. Current AZ-900: Microsoft Azure Fundamentals exam objectives that align with those weeks.
5. Reputable public Azure practice material that reinforces the same objectives.

Do not include content assigned after Week 6. Do not copy certification exam dumps, proprietary question banks, or copyrighted questions. Create original questions aligned with the AZ-900 skills measured.

ASSESSMENT REQUIREMENTS

Create a 60-question test bank worth 60 points:

* Each question is worth one point.
* Include multiple-choice questions.
* Include true-or-false questions.
* Include multiple-select questions.
* Include interactive flash cards.
* Include scenario-based questions.
* Include matching, categorization, or another accessible interactive strategy when technically appropriate.
* Balance questions across Weeks 1–6.
* Include easy, moderate, and challenging questions.
* Emphasize application and conceptual understanding instead of simple memorization.

For every question, include:

* The correct answer.
* A thorough explanation of why the correct answer is correct.
* An explanation of why each incorrect option is wrong.
* The associated week.
* The Azure topic or objective.
* Clear corrective feedback written for beginning Azure students.

PRACTICE MODE

Make Practice Mode the default.

In Practice Mode:

* When a student answers incorrectly, display corrective feedback immediately.
* Allow the student to change the answer and retry the same question until it is correct.
* Do not require the student to restart or repeat the entire simulation.
* Award the question’s point only once.
* Allow students to skip any question.
* Clearly mark skipped questions in the question navigator.
* Allow students to return to skipped questions at any time.
* Do not treat a skipped question as permanently incorrect.
* Students must be able to finish all skipped questions before achieving 60 points.
* Allow unlimited full-game retakes.
* Save the best score locally on the student’s device when browser storage is available.

PROGRESS AND GAMIFICATION

Use a World Cup soccer theme with:

* An animated soccer field.
* A player or ball advancing as the student progresses.
* A scoreboard showing points earned out of 60.
* A progress bar.
* A 60-question navigator.
* Visual indicators for current, correct, incorrect, retried, and skipped questions.
* Positive goal celebrations for correct answers.
* Supportive “saved by the keeper” feedback for incorrect answers.
* A final championship screen.
* A printable completion result showing the score, completion date, and weekly performance.
* A review section listing concepts that need additional study.

TEN-POINT MILESTONE SCREENS

Display a full milestone celebration when the student earns 10, 20, 30, 40, 50, and 60 points.

Trigger milestones according to points earned—not the number of questions viewed. Retried and skipped questions must not incorrectly activate milestone screens.

Each milestone must include:

* An animated celebration.
* The score achieved.
* An encouraging World Cup narrative.
* A different verified World Cup fun fact.
* A visual six-stage milestone tracker.
* A “Continue the Quest” button.
* An accessible dialog structure, keyboard focus, and screen-reader announcement.
* A brief original sound effect when sound is enabled.

The introduction should include:

* Original synthesized stadium percussion.
* Crowd-cheering effects.
* An original spoken chant: “AZ-900—let’s go! Cloud champions, take the field!”
* A short original closing horn flourish.
* A visible countdown or progress indicator.
* A “Skip Intro” button.
* A “Replay Intro” button.
* A master Sound On/Off control.
* Automatic fade-out or clean stopping after approximately 10 seconds.

Do not use Queen’s “We Will Rock You,” commercial recordings, copyrighted music, recognizable melodies, or external copyrighted audio.

Generate the introduction with embedded JavaScript and the Web Audio API so the game remains a self-contained HTML file. Start audio only after the student clicks “Enter the Stadium” to comply with browser autoplay restrictions.

Sound must be optional and must not be required to understand or complete the game.

* Full keyboard navigation.
* Visible keyboard focus indicators.
* Semantic headings and controls.
* Proper labels and instructions.
* Screen-reader announcements for feedback, score changes, milestones, and progress.
* Do not communicate status using color alone.
* Provide high-contrast mode.
* Provide enlarged-text mode.
* Provide Sound On/Off controls.
* Respect reduced-motion preferences.
* Provide text equivalents for important audio.
* Do not place essential educational information only inside animation.
* Use accessible dialogs for milestone screens.
* Maintain readable color contrast.
* Use large touch targets.
* Avoid rapid flashing.
